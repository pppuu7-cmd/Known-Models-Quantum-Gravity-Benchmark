## T3-01 immediate motivation

Second-wave S2-M05 showed that type-II Virasoro-Shapiro pole support differs from one simple Huang-Remmen single-mass UV comparator. That was only a one-comparator distinction.

Bespoke dual-resonance constructions are a much stronger adversary because published constructions allow user-defined mass spectra while retaining dual resonance, tame UV behavior and unitary parameter regions. Later partial-wave analyses significantly restrict viable bespoke families, especially excluding asymptotically nonlinear Regge trajectories in the studied class.

Therefore the third-wave string/UV discriminator must be stronger than pole locations alone.

`I_UV = {pole support, residue/spin decomposition, crossing/duality, Regge trajectory, high-energy boundedness/sum rules, low-energy coefficient correlations}`.
