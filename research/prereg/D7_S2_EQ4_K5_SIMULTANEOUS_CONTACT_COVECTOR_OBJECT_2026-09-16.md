## PASS / BLOCKED / INVALID

`PASS_SCOPED` iff all seven required fields are source-authoritatively defined and the ten raw contact covectors can be constructed mechanically on the shared gauge-fixed group-variable tangent domain with no outcome-sensitive convention.

`BLOCKED_SCOPED` iff at least one essential field needed to define the raw shared contact-covector object is absent or inaccessible in admissible authority. The missing field must be localized exactly.

`INVALID` iff PASS requires freezing/identifying auxiliary variables without source authority, inserting a quotient/metric/normalization, using V8, importing textbook contact geometry, or changing criteria after reading the contact formula.

This gate has no `FAIL` branch for a rank/independence property: it is an object-definition gate. Algebraic rank of the resulting contact system, if the object is authorized, belongs to a separately preregistered child gate.
