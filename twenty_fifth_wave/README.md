## Result

- too broad to select a small hierarchy (universal double copy);
- too scoped to be the required full parent (self-dual gravity);
- sufficiently rigid but already a known comparator/deformation architecture (string bootstrap, Coon/bespoke/generalized dual resonance).

The next methodological search axis is **cross-representation rigidity**: one parent parameter set must simultaneously predict in-out scattering, in-in/CTP causal/noise structure and relational/quantum-channel gravity observables.

This is a design redirection, not a claim that cross-representation consistency is unique to KG.
