## T6-01 frozen assumptions

The massless-spin-2 attribution statement is never used without its scope. The baseline assumptions are:

1. one interacting long-range massless spin-2 degree of freedom around Minkowski;
2. locality / no instantaneous signalling or local factorization;
3. unitarity;
4. relativistic/luminal massless propagation and the corresponding Lorentz/gauge consistency;
5. universal leading coupling to conserved matter stress energy;
6. leading low-derivative / infrared interaction sector.

Under this scope, known spin-2 bootstrap and BRST/deformation results recover GR interactions at leading long distances, with higher-derivative EFT corrections remaining possible. The benchmark therefore treats **massless spin-2 attribution as gravity-sector identification, not KG novelty**.

## T6-04 nonlocal causality guardrail

Recent nonlocal-gravity literature sharpens the distinction between different causal notions. Entire-form-factor constructions can be ghost-free and have good perturbative/macroscopic propagation properties, yet explicit 2026 work exhibits a large subclass admitting Gödel-type vacuum solutions with closed timelike curves. Thus

`ghost-free + UV finite/renormalizable + healthy perturbative spectrum != global causal consistency`.

A future KG model using controlled nonlocality must audit separately

`I_causal_NL={retarded support/front velocity,microcausal tails,no-signalling,global causal solutions,initial-value problem}`.

A model is not rejected solely because a particular nonlocal class has an acausal solution; the result is a mandatory separate gate.
