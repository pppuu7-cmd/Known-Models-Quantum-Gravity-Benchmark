## D. 2025–2026 localized/non-uniform phase programme — powerful prediction, not yet independent matrix-side validation

## E. Large-N / DLCQ completion gap

A finite-N BFSS system has fixed longitudinal momentum units. The claim that it defines uncompactified eleven-dimensional M-theory requires a controlled large-N limit, including compatibility of the limit with energy, scattering, threshold-bound-state and infrared limits.

Existing strong tests support the conjecture but do not constitute a general theorem that every target-sector M-theory observable is recovered with a single controlled error norm.

Classification:

`BLOCKED_GENERAL_LARGE_N_DLCQ_TO_UNCOMPACTIFIED_MTHEORY_COMPLETENESS_AND_UNIFORM_ERROR_CONTROL`.

## F. Terminal-object requirement

A terminal BFSS family object should freeze one of two routes:

1. **scattering route:** matrix-side observable -> large-N extrapolation -> 11D Lorentzian scattering observable -> same-domain SUGRA/string comparator -> finite-N/IR/truncation errors;
2. **thermal route:** prospectively chosen matrix thermodynamic/transition observable -> continuum + large-N + low-T extrapolation -> corresponding localized/non-uniform black-hole prediction -> independent uncertainties on both sides.

The older D0 thermodynamic test is a strong scoped PASS but does not by itself close all M-theory sectors. The new 2026 localized-phase target is especially promising because it offers a falsifiable matrix-side holdout.
