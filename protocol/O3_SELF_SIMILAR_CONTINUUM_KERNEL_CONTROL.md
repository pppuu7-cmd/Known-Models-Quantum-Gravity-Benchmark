## 1. Finite microscopic parent

Consider a semi-infinite uniform linear chain with basis states `|n>`, `n=0,1,2,...`, onsite parameter `m^2` and nearest-neighbor hopping `g`:

`H = m^2 Σ_n |n><n| + g Σ_n (|n><n+1| + |n+1><n|)`.

The microscopic law uses only two continuous parameters `(m,g)` plus the statement of exact translation/self-similarity along the tail.

Define the boundary resolvent

`G(z)=<0|(z-H)^(-1)|0>`.

## 2. Exact Schur/self-similarity recursion

After removing site `0`, the remaining tail is isomorphic to the original semi-infinite chain. Schur complementation therefore gives

`G(z)=1/[z-m^2-g^2 G(z)]`.

Equivalently,

`g^2 G(z)^2 - (z-m^2)G(z) + 1 = 0`.

The asymptotic condition `G(z)~1/z` fixes the physical branch uniquely:

`G(z)=[(z-m^2)-sqrt((z-m^2)^2-4g^2)]/(2g^2)`.

This is non-rational and has a branch cut rather than finitely many poles.

## 3. Spectral density

For real `E` inside

`m^2-2g < E < m^2+2g`,

the retarded boundary value has

`Im G(E+i0) = -sqrt(4g^2-(E-m^2)^2)/(2g^2)`.

Hence

`rho(E)=-(1/pi) Im G(E+i0)`

`= sqrt(4g^2-(E-m^2)^2)/(2 pi g^2)`

inside the band and zero outside.

The semicircle density is normalized:

`∫ rho(E)dE = 1`.

Thus an entire continuum spectral function is fixed by only `(m,g)` and a finite self-similarity law.

Classification:

`A2_PASS__FINITE_RECURRENCE_FIXES_NONRATIONAL_CONTINUUM_KERNEL`.

This is stronger than choosing a spectral density by hand.

## 4. Why the rational-localization no-go does not apply

The parent hidden system is infinite dimensional. Its boundary resolvent has a branch cut and cannot be represented by finitely many ordinary auxiliary poles.

Therefore it genuinely escapes the **finite rational** localization theorem of Iter074.

This proves that the O3 target region is mathematically nonempty:

`finite microscopic rule` does not imply `finite-dimensional hidden system`.

An infinite structure may be generated by finite recurrence data.
