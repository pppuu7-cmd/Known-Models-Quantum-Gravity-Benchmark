# P4 Spectral-Action / Isospectral-Geometry Nonuniqueness Gate

**Status:** exact scoped operator-selection prefilter.  
**KMQGB iteration:** 137.  
**Purpose:** test whether a bosonic spectral action depending only on the eigenvalue spectrum of a Dirac-type operator can uniquely select physical geometry/dynamics.

## 1. Scope

The Chamseddine-Connes bosonic spectral action has the form

`S_spec[D] = Tr f(D/Lambda)`

(or an equivalent even function of `D^2`).

For fixed `f` and `Lambda`, this depends only on the eigenvalues of `D`, including multiplicities.

This gate is about the **spectral action used as a selector by itself**. It does not claim that a full spectral triple `(A,H,D)` contains only eigenvalue data; the algebra representation and other triple data can carry additional information.

## 2. Exact degeneracy

There exist non-isometric manifolds with identical Dirac spectra.

A simple established class arises from flat tori: non-isometric flat tori that are isospectral for the Laplacian on functions can, for the associated trivial spin structures, also be isospectral for the Dirac operator.

Therefore there can exist

`(M1,g1) not isometric to (M2,g2)`

with

`Spec(D1) = Spec(D2)`.

For every admissible profile `f` and every common scale `Lambda`, it follows exactly that

`Tr f(D1/Lambda) = Tr f(D2/Lambda)`.

Hence the complete bosonic spectral-action value is identical on the pair.

## 3. Consequence for variational selection

Any proposed parent of the form

> choose the physical geometry as the unique minimizer/extremum of a bosonic action that depends only on `Spec(D)`

cannot distinguish Dirac-isospectral non-isometric geometries when both belong to the admissible domain.

This is stronger than a finite heat-kernel truncation ambiguity: the degeneracy persists for the **full spectral action**, not merely the first few Seeley-DeWitt coefficients.

Classification:

`A2 BLOCKED__SPECTRAL_ACTION_ALONE_CANNOT_RESOLVE_DIRAC_ISOSPECTRAL_NONISOMETRIC_GEOMETRIES`.

## 4. Legitimate escape routes

A serious spectral parent can evade the gate only by using and physically deriving additional information, for example

1. the full algebra representation `A -> B(H)`, not only `Spec(D)`;
2. eigenfunction/correlation/localization data;
3. a state/measure or boundary observable distinguishing the isospectral configurations;
4. additional relational/corner/causal data;
5. a hard-scattering observable generated by the full triple and shown to differ even when the bare spectrum is degenerate.

But those extra structures are then part of the parent and must themselves satisfy A1/A2/A3.

## 5. Relation to reconstruction theorem

There is no contradiction with the spectral-triple reconstruction theorem.

The reconstruction theorem uses the **full commutative spectral triple** satisfying its axioms, including the algebra and its action on `H`, to reconstruct Riemannian geometry.

The present gate says something narrower and directly relevant to parent selection:

`eigenvalue spectrum / spectral action alone != unique geometry`.

Thus

`full triple can encode geometry`

is not equivalent to

`spectral action uniquely selects the physical triple`.
