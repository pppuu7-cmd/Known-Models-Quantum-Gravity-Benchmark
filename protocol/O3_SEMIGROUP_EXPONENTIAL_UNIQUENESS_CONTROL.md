# O3 Semigroup-to-Exponential Uniqueness Control

**Status:** exact A2 positive control / comparator-contained.  
**KMQGB iteration:** 075.  
**Purpose:** exhibit a non-rational form factor whose functional freedom is genuinely collapsed by a finite functional law, then test whether uniqueness is sufficient for P4.

## 1. Parent functional law

Let `F(z)` be an analytic/entire scalar form factor satisfying

1. `F(0)=1`;
2. exact composition/semigroup law `F(z+w)=F(z)F(w)` for all complex `z,w` in the declared domain.

The composition law is finite information: it does not specify an arbitrary function value at every momentum.

## 2. Exact uniqueness theorem

First, `F` has no zeros. If `F(z0)=0`, then

`1 = F(0) = F(z0)F(-z0) = 0`,

a contradiction.

Differentiate the semigroup equation with respect to `w` at `w=0`:

`F'(z) = F(z) F'(0)`.

Define the one constant

`c = F'(0)`.

Then `F` obeys the first-order ODE

`F'(z)=cF(z)`, `F(0)=1`,

whose unique analytic solution is

`F(z)=exp(c z)`.

Thus the infinite Taylor tower is fixed by one parameter:

`F(z)=Σ_n c^n z^n/n!`.

This is an exact example in which the KMQGB A2 functional-freedom problem is solved rather than hidden by choosing a basis function by hand.

## 3. Why this is scientifically useful

The result establishes a positive control:

`finite functional composition law -> unique transcendental kernel up to finite data`.

Therefore O3 is not logically impossible. A non-rational kernel can in principle be derived from a finite rule without arbitrary function freedom.

This is categorically different from writing `F=exp(cz)` as an ansatz with no derivation.

## 4. A3 comparator test

Exponential/entire form factors are a major registered nonlocal/infinite-derivative gravity comparator class.

Moreover Modesto and Calcagni, *Tree-level scattering amplitudes in nonlocal field theories*, arXiv:2107.04558, prove for a special stable/unitary class of weakly nonlocal theories that tree-level `n`-point amplitudes equal those of the underlying local theory; for the corresponding gravity class, the tree-level amplitudes equal Einstein gravity.

Thus the semigroup uniqueness theorem closes A2 but does **not** by itself produce a Candidate Gravity residual.

Classification:

`A2 PASS__FUNCTION_UNIQUELY_FIXED_BY_SEMIGROUP`

but

`A3 FAIL__KNOWN_ENTIRE_NONLOCAL_COMPARATOR`

and, for EOM-related/tree-equivalent subclasses,

`A4 NO_NEW_TREE_GRAVITON_RESIDUAL`.

## 5. Lesson for O3

A successful O3 parent needs **two different forms of rigidity**:

1. **functional rigidity** — a finite law uniquely fixes the non-rational kernel;
2. **physical/comparator rigidity** — the resulting kernel creates a hard/CTP relation not removable by field redefinition and not already contained in known nonlocal/string/AS/discrete architectures.

Uniqueness of a function is not the same thing as novelty of a physical theory.

## 6. Stronger target generated by this control

The next O3 search should prefer a finite functional law whose unique solution is

- non-rational (to evade finite mediator localization);
- not merely an exponential EOM-dressing of GR;
- compatible with a parent-fixed retarded/CTP prescription;
- tied to a nontrivial four-graviton or cross-representation invariant;
- and not a known q-string/Veneziano/string form in disguise.
