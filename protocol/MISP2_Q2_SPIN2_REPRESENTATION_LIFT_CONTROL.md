## 2. Exact unitarity and finite range

If `A(k)` is unitary, then

`A(k)^(tensor 4)`

is unitary. The symmetric subspace is invariant, so its restriction `U_2(k)` is exactly unitary.

Each matrix element of `U_2(k)` is a degree-four polynomial in matrix elements of `A(k)`.

Because the BCC Weyl symbol is a finite Laurent/trigonometric polynomial, a finite product of four such symbols is still a finite Laurent polynomial. Therefore `U_2(k)` is an exact finite-range translation-invariant free update, with support contained in the four-fold Minkowski sum of the original finite neighborhood.

Thus the control passes the **free finite-range/unitarity** part of Q2 without a fitted form factor.

## 3. Spin-axis structure

Write the Weyl symbol as

`A(k) = exp[-i omega(k) n_hat(k).sigma]`

whenever `n(k) != 0`, with fundamental eigenvalues

`exp[-i omega(k)]`, `exp[+i omega(k)]`.

In the spin-2 representation, let `J_n` denote the angular-momentum generator along the same effective axis `n_hat(k)`. Then

`U_2(k) = exp[-i 2 omega(k) J_n]`.

The five spin-2 magnetic sectors `m=-2,-1,0,+1,+2` have eigenphases

`phase_m = -2 m omega(k)`.

Hence the extreme helicity sectors have phases

`m=+2: -4 omega(k)`,

`m=-2: +4 omega(k)`.

The update commutes with `J_n`, so these sectors are exactly preserved at the free one-particle level.

## 6. Why the factor four is representation-theoretic

The fundamental update is generated by `sigma=2J_(1/2)`:

`A = exp[-i 2 omega J_(1/2,n)]`.

Using the same group element in the spin-2 representation gives

`U_2 = exp[-i 2 omega J_(2,n)]`.

The helicity-2 states have `J_(2,n)=±2`, hence phases `∓4 omega`.

The factor is therefore not a floating-point artifact and not a peculiarity of one momentum direction. It follows from using the **same SU(2) group element** in the higher-spin representation.
