# P4 Same-Factorization Contact-Difference Theorem

**Status:** permanent hard-amplitude synthesis gate.  
**KMQGB iteration:** 083.  
**Purpose:** state precisely why a new local analytic tree-level four-graviton amplitude cannot differ from GR while keeping the same particle spectrum and all GR factorization data, except through ordinary contact/EFT terms.

## 1. Assumptions

Compare a candidate tree-level physical four-graviton amplitude `M4` with a reference GR amplitude `M4_GR` in a common helicity/kinematic domain.

Assume

1. the same propagating asymptotic particle spectrum in the domain;
2. the same physical factorization pole locations in `s,t,u`;
3. the same residues on every such pole, including the same lower-point on-shell amplitudes entering factorization;
4. no extra branch cuts/essential singularities at tree level;
5. ordinary locality/polynomial boundedness so the remaining pole-free tree contribution is a local analytic contact amplitude order by order.

## 2. Pole cancellation

Define

`Delta M4 = M4 - M4_GR`.

At each physical pole, equal residues imply cancellation of the principal part. Since the pole locations are also equal, `Delta M4` has no physical factorization poles in any channel.

Under the stated tree-level analytic/local assumptions, `Delta M4` is therefore a contact amplitude.

For gravitons its helicity/tensor polynomial can be generated by local generally covariant higher-curvature/higher-derivative operators, modulo field redefinitions/on-shell identities.

Thus, in the declared low-energy local analytic domain,

`same poles + same residues + local analytic difference`

implies

`Delta M4 in full matched gravitational EFT / C5 contact space`.

## 3. Immediate consequence

A future P4 candidate with the ordinary massless graviton spectrum cannot escape full C5 at tree level merely by claiming a new recursive construction while reproducing all GR factorization data.

If the recursion changes no poles/residues, its genuinely new information must be a contact term. Local analytic contact freedom is already registered in full C5.

This includes many prospective constructions based only on

- gluing GR three-point vertices;
- standard Berends-Giele/BCFW-like factorization with no new boundary data;
- standard unitarity/factorization plus a different bookkeeping representation;
- a finite automaton or tensor network that exactly reproduces the same on-shell lower-point data and remains local/analytic in the IR.

## 4. Escape branches

To produce a comparator-orthogonal hard object, at least one assumption must fail in a controlled way.

### S1 — new poles/states

Extra poles or changed residues imply additional degrees of freedom or modified three-point data. Apply E2/C4/C6/string/massive-spin2/tower comparators and consistency taxes.

### S2 — pole-free but non-polynomial/nonlocal analytic structure

An entire/transcendental pole-free contact function is E1/O3 territory. It must pass functional-freedom, field-redefinition/tree-equivalence, causality and known nonlocal comparator gates.

### S3 — branch cuts/continuum/nonperturbative singularities

Cuts or essential/nonperturbative structures invoke E1/E2/E3. Positive two-point Källén-Lehmann cuts are continuum-mediator degenerate; standard graviton/matter loop cuts belong to matched C5/known-sector comparators. A candidate must identify an additional intrinsic gravitational higher-point relation.

### S4 — modified factorization/quantum dynamics

If ordinary factorization itself changes, the proposal enters E4/E5 and must establish unitarity/probability/no-signalling/causal consistency and an observational map.

## 5. Higher-point extension

The same logic applies recursively: if all lower-point factorization data agree with a comparator, the difference at the next tree order is a contact ambiguity until a new singularity or modified factorization rule appears.

Therefore a finite recursive parent built solely from already-matched lower-point GR data cannot create KG novelty without specifying where the first comparator-orthogonal boundary/contact/nonlocal datum enters.
