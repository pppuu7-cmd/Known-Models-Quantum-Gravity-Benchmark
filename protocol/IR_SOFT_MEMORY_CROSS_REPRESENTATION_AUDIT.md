# IR Soft / Memory / In-In Cross-Representation Audit

**Status:** frozen comparator/design audit / no Candidate Gravity promotion.  
**Purpose:** determine whether asymptotic-symmetry relations linking scattering, gravitational memory and in-in observables can serve as a novel parent-selection principle.

## 1. The gravitational IR triangle

In asymptotically flat GR, the leading soft graviton theorem, BMS asymptotic symmetry and displacement memory are different representations of the same infrared structure.

Recent 2025 work makes the local detector-frame connection explicit and also derives corresponding soft Ward identities for equal-time in-in correlators.

Thus one obtains a genuine cross-representation chain

`asymptotic symmetry <-> in-out soft scattering <-> local memory/response <-> equal-time in-in Ward identity`.

This is exactly the type of representation linkage that KMQGB wants a parent to predict.

## 2. Why it is not Candidate Gravity novelty

The relation is already present in ordinary GR/perturbative quantum gravity and follows from asymptotic diffeomorphism symmetry plus the universal infrared graviton coupling.

Therefore

`BMS + soft theorem + memory + in-in soft identity`

is a **gravity-attribution / cross-representation anchor**, not a beyond-C5 residual.

A future KG may be required to preserve the appropriate IR triangle, but reproducing it cannot promote an ansatz.

## 3. Leading and subleading structure

Leading soft universality is tied to the massless spin-2/equivalence structure. Subleading and logarithmic soft relations provide additional asymptotic consistency information, but they remain part of the known infrared structure of GR/C5 within their scope.

Candidate-specific novelty must therefore live in a harder/non-universal relation while remaining consistent with these soft Ward identities.

## 4. In-in bridge

Equal-time in-in soft theorems provide a particularly useful representation map because they connect asymptotic/soft scattering logic to real-time or detector-frame correlators.

For KMQGB this shows that a legitimate parent can link `R_S` and `R_CTP/R_REL` without introducing new dynamics.

Hence **cross-representation linkage itself is not enough**; the linked numerical/tensor relation must survive the full C5 comparator.

## 5. Memory as a detector/relational block

Gravitational memory should be formulated in local detector or relational coordinates before being stacked with scattering data. Large residual diffeomorphisms and BMS transformations describe the same physical effect in the relevant mapping.

A gauge-coordinate memory difference is not a residual.

## 6. Parent-principle conclusion

Asymptotic symmetry is a strong **constraint generator** but not, by itself, a selector of a novel quartic/higher kernel.

It fixes universal soft data while leaving hard finite-energy amplitude information highly underdetermined.

Thus it belongs with positivity/spectral constraints in the category

`STRONG_CONSISTENCY_RELATION__INSUFFICIENT_NOVEL_KERNEL_SELECTION`.

## 7. Use in future KG

Retain the IR triangle as a mandatory anchor:

1. candidate hard/cross-regime deformation must reduce to the correct soft graviton structure;
2. the same parent must give the corresponding local-memory/in-in Ward relation;
3. any candidate-specific residual should be chosen orthogonal to this already-C5 universal direction;
4. violations of the soft/memory anchor are consistency/gravity-attribution failures unless the candidate explicitly changes the asymptotic symmetry assumptions and pays that separate tax.

## 8. Promotion status

No KG ansatz is promoted. The audit narrows the parent search by showing that a highly nontrivial scattering-to-response relation can still be fully C5/GR-degenerate.
