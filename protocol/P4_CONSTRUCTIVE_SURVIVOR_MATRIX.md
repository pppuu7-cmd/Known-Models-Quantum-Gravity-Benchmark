# P4 Constructive Survivor Matrix

**Status:** active search-routing authority.  
**KMQGB iteration:** 070.  
**Purpose:** stop repeated exploration of branches whose failure mode is already known and identify the genuinely open constructive cells for P4.

## 1. Matrix rule

Every candidate is routed through

`A1 explicit parent -> A2 finite freedom -> A3 comparator survival -> A4 explicit hard/cross-representation relation`.

A branch is **closed for novelty** if its characteristic realization necessarily fails one of these gates in the declared domain. A broad architecture is not globally falsified merely because one representative fails; the matrix records what additional ingredient is required to reopen it.

## 3. What cannot be P4 merely by relabeling

The following transformations do not reopen a closed cell:

- choosing a different finite-parameter basis function inside an arbitrary form-factor class;
- rescaling a known string/triple-product pole mass;
- digitizing/Trotterizing a known continuum comparator;
- writing a known amplitude in QCA, tensor-network or worldsheet variables;
- taking a finite-dimensional subfamily of full C5 without an observable outside the C5 manifold;
- using a projective ratio when absolute normalization is required for the residual;
- declaring lattice Lorentz violation as novelty without entering E5 and its comparator/phenomenology taxes.

## 4. Genuinely open constructive cells

After the audits through Iter070, the search has four high-value open cells.

### O1 — E3 Lorentzian nonperturbative hard sector

Required object:

`finite parent saddle/sector data -> derived nonperturbative weight+phase -> Lorentzian hard graviton observable -> same-parent retarded/CTP response`.

Must be invisible to every finite local derivative order or otherwise demonstrably outside full C5, while not reducing to a known string/matrix/asymptotic-safety/nonperturbative comparator.

Current blocker: known entropy/black-hole/resurgence ideas generally do not derive the complete hard graviton object.

### O2 — finite algebraic/causal parent with dynamical selection

Required object:

`finite algebraic transfer/constraint object -> unique hard interaction hierarchy`,

not merely a gluing/projector/overlap consistency scaffold.

It must derive both scattering and real-time response with shared finite data and survive HST/operator-algebra/spinfoam/GFT containment.

Current blocker: known algebraic emergence results reconstruct geometry/Einstein dynamics but not a unique hard four-graviton/CTP hierarchy outside comparators.

### O3 — parent-fixed D-nonlocal analytic class

Required object:

`finite microscopic law -> unique/near-unique nonlocal kernel`,

with no arbitrary form factor or spectral density, plus exact retarded support/causality and an explicit hard relation.

Current blocker: most nonlocal models choose a function; known entire/form-factor and AS/nonlocal constructions occupy large comparator spaces.

### O4 — fundamental modified quantum dynamics with gravity-specific hard relation

Required object:

`finite E4 law -> complete-positive/consistent gravity dynamics -> hard graviton + CTP relation`,

which cannot be reinterpreted as ordinary reduced open-system dynamics or a generic bath/noise kernel.

Current blocker: existing collapse/hybrid/noise proposals usually fail either gravity attribution, relativistic consistency, or the required hard-spin-2 hierarchy.

## 5. Priority ordering

The matrix recommends the following search priority:

1. **O1** — strongest chance of an actual Beyond-C5 object while preserving ordinary GR IR;
2. **O2** — strongest chance of a truly finite parent selector if a hard hierarchy can be derived;
3. **O3** — viable only with a uniqueness theorem/microscopic derivation strong enough to defeat functional freedom;
4. **O4** — highest consistency tax and most severe attribution burden.

QCA/discrete work is retained as a microscopic-control branch but should not consume primary P4 effort unless it explicitly enters a hard E5/nonanalytic/collective escape regime and survives discrete comparators.

## 6. Hard near-survivor standard

A future search hit is worth detailed development only if it arrives with at least three of four items already present:

- `H1`: explicit parent/constructive object;
- `H2`: demonstrably finite parent freedom;
- `H3`: explicit hard quartic/higher or cross-representation relation;
- `H4`: prima-facie outside the strongest registered comparator architecture.

If only one item is present, preserve as background/comparator evidence rather than creating a new candidate branch.

## 7. Search stop rules

Stop a literature branch immediately when any is established:

- the claimed parent is only an effective parameterization with an unselected function;
- the minimal rigid solution is a known string/matrix/AS/discrete comparator;
- the only deviation is a low-energy local analytic Wilson tower inside full C5;
- the required absolute observable depends on an unfixed normalization that can only be fitted from the candidate data;
- hard four-point/CTP data are absent and the source does not contain a mechanism capable of deriving them.

## 8. Score consequence

The matrix is search routing, not a constructive survivor.

R4 remains unchanged until one O1-O4 object satisfies the actual P4 rubric. Its value is efficiency: the next iterations now search the four genuinely open cells rather than cycling through already classified architecture families.
