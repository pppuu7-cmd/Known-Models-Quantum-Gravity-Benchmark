# Amplitude Parent-Principle Saturation Audit

**Status:** frozen design audit / no Candidate Gravity promotion.  
**Purpose:** record which seemingly strong amplitude-only principles fail to select a novel Candidate Gravity hierarchy because they are either too broad, too narrow, or already map to known comparator families.

## 1. Universal double copy / generalized color-kinematics

**Result:** `INSUFFICIENT_SELECTION__SPANS_FULL_PARITY_EVEN_4GRAVITON_EFT`.

The 2026 universal double-copy construction generalizes color-kinematics duality to the complete basis of four-point color structures and shows that the resulting construction spans the entire parity-even four-graviton higher-derivative EFT (modulo the separately representable Lovelock `R3` corner in high dimensions).

Therefore “admits a generalized double copy” is not a low-dimensional kernel-selection principle for four-graviton Candidate Gravity. It is a structural factorization language that is compatible with essentially the whole target EFT space.

A future KG may still possess a double-copy representation, but novelty must come from an additional rule selecting a very small locus inside the universal double-copy space.

## 2. Self-dual / celestial-integrable gravity

**Result:** `INSUFFICIENT_FULL_PARENT__SCOPED_INTEGRABLE_SECTOR`.

Self-dual gravity supplies strong infinite-dimensional symmetry/integrability structure, with one-loop-exact all-plus amplitudes and celestial `w_(1+infinity)` organization.

However the known quantum self-dual gravity sector is not the required complete unitary four-dimensional gravity parent for KMQGB. Its nontrivial all-plus amplitudes coincide with the corresponding pure-Einstein amplitudes in the reviewed sector, while the theory is a chiral/self-dual truncation rather than a full parity-complete candidate.

Thus self-dual integrability is a useful structural precedent but not presently a novel quartic/higher KG parent.

## 3. Minimal Regge-zero principle

**Result:** `STRING_STRUCTURAL_COMPARATOR`.

The 2026 “Strings from Almost Nothing” bootstrap shows that crossing/unitarity plus universal Regge-zero structure, ultrasoft behavior and the minimality condition that residues contain only the consistency-mandated zeros uniquely select Veneziano/Virasoro-Shapiro string amplitudes (with related results beyond four-point).

Therefore the strongest known “minimal zeros” principle already leads directly to the string comparator manifold.

## 4. Controlled nonminimal-zero / trajectory deformations

**Result:** `KNOWN_DUAL_RESONANCE_DEFORMATION_SPACE`.

Relaxing string minimality does not automatically create a novel KG principle. Known examples include

- Coon/q-deformed amplitudes with nonlinear/logarithmic Regge trajectories;
- bespoke dual-resonance amplitudes with customizable spectra;
- generalized/hypergeometric Veneziano families;
- deformations of the fully permutation-invariant Virasoro-Shapiro amplitude.

Parts of these families are compatible with partial-wave positivity/unitarity in scoped regions, while other regions fail positivity, branch-cut or Regge-sum-rule tests.

Hence “add one extra zero/one trajectory parameter” must be treated as a comparator/deformation-family question, not as a new KG principle by default.

## 5. Design redirection — cross-representation rigidity

**Result:** `NEXT_SEARCH_DIRECTION__NOT_YET_NOVELTY`.

The amplitude-only search repeatedly encounters either

- known rigid comparator solutions (string/bootstrap),
- broad parameterizations (double copy/bespoke), or
- scoped/truncated sectors (self-dual gravity).

The next admissible methodological direction is therefore to require one parent object to predict **multiple representations of the same quantum gravitational dynamics** with shared parameters, for example

1. in-out four-graviton scattering / helicity amplitudes;
2. in-in/CTP retarded response and symmetrized/ordered kernels;
3. relational/quantum-channel observables or soft/tidal gravity-attribution anchors.

This is called **cross-representation rigidity**.

It is not claimed to be KG novelty by itself. Ordinary QFT/string/asymptotic-safety parents may also satisfy such consistency. The point is to enlarge the physical data vector while keeping the parent parameter set shared, thereby creating additional comparator-orthogonal consistency directions.

## 6. Required cross-representation rule

If representation blocks `R_a` are all derived from one parent parameter vector `theta`, stack their physical observables as

`y_XR = col(y_inout, y_CTP, y_relational, ...)`.

Comparator and candidate parameters remain shared wherever the parent theory says they are shared.

Define the same residual-space geometry on the stacked vector:

`A_XR = Sigma_XR^(-1/2) J_union,X R`,

`Pi_XR = I - A_XR A_XR^+`.

The useful gain is not the raw number of representations but whether the stacked physical dimension grows faster than the union comparator rank.

## 7. Guardrails

Do not

- call in-out/in-in agreement a KG fingerprint by itself;
- assume KMS/FDR or optical-theorem relations are gravity-specific;
- clone one shared parent parameter independently in each representation;
- compare different truncation orders or validity domains as if they were the same object;
- use a representation map that fails the kinematic-projection-rank gate.

## 8. Current conclusion

Amplitude-only minimality has not yet yielded a novel KG parent principle outside known comparator spaces.

The next search should test whether a **small shared parameter set can simultaneously overconstrain scattering, causal response and relational quantum-channel sectors** in a way that survives full C5, string-like, asymptotic-safety and open-system comparators.

No Candidate Gravity ansatz is promoted.
