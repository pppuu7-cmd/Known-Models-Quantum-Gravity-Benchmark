# Type-II String as Structural Adversary to Quartic-First Candidate Gravity

**Status:** frozen comparator/design protocol / no KG promotion.  
**Purpose:** prevent the quartic-first KG search from rediscovering a known string-like architecture and mistaking cross-order rigidity for uniqueness.

## 1. Why type-II string is the key adversary

The current conservative KG search front preserves the GR two- and three-point sectors and places the first exploratory deformation at four-point/higher order.

Type-II superstring theory is a concrete known realization of this structural pattern:

- its low-energy limit is type-II supergravity/GR in the graviton sector;
- the first purely gravitational alpha-prime correction occurs at eight-derivative order;
- lower `R^2` and `R^3` corrections are absent in the type-II tree-level graviton sector;
- the leading tree-level correction is proportional to `zeta(3) alpha'^3 R^4` with a tensor contraction fixed by the parent string theory.

Therefore `GR 2pt + GR 3pt + first R4 correction` is **not** a unique Candidate Gravity architecture.

## 2. Fixed tensor structure

A standard type-II tree-level form is schematically

`e^(-2phi) [ t8 t8 R^4 + (1/8) epsilon10 epsilon10 R^4 ]`

up to convention/sign/frame details and the required completion with other string fields.

The key design lesson is not the precise ten-dimensional contraction but the fact that the parent theory fixes correlated tensor structures; they are not independent phenomenological coefficients chosen after observing data.

Any future KG quartic parent must similarly derive its tensor/helicity ratios.

## 3. Full-amplitude cross-order rigidity

The flat-space four-graviton Virasoro-Shapiro factor has a low-energy expansion whose first nonzero correction is order `alpha'^3`.

Schematically,

`F_VS = 1 + O(zeta(3) alpha'^3 stu) + higher zeta-weighted terms`.

The exact normalization depends on dimensionless Mandelstam conventions, but the crucial point is that one parent amplitude fixes an infinite sequence of higher-derivative coefficients rather than assigning one independent Wilson coefficient at every order.

This is precisely the kind of cross-order rigidity KMQGB seeks — and therefore it must be treated as a **known comparator pattern**, not KG novelty.

## 4. Low-energy versus cross-regime quotient

At any finite low-energy order, the string expansion maps into gravitational EFT/C5 Wilson coefficients.

Therefore

`finite string R4/D^(2n)R4 coefficients != beyond-C5 residual`.

Potential string-specific distinction appears only when enough linked coefficients or the full cross-regime analytic/pole structure is retained in a validity domain where the comparator is also defined.

## 5. New mandatory comparator branch

For any future quartic-first KG seed, add a string-like structural adversary check:

1. Does the seed preserve GR 2pt/3pt and first modify 4pt/higher?
2. Does it generate an `R4`-type low-energy tower with few shared parameters?
3. Can its coefficient ratios be reproduced by a type-II/string-like amplitude expansion after allowed normalization/scale profiling?
4. Does its full amplitude have the same pole tower, Regge behavior, crossing structure or zeta/transcendental hierarchy as a known string amplitude?
5. If not, what exact comparator-resistant relation remains in the common domain?

A low-energy mismatch with one specific string point is insufficient; broader string/dual-resonance families remain relevant.

`I_Q4 = {rho4, r_2,1, r_4,1, r_4,2, ..., cross-regime helicity shapes, pole/support data}`

## 7. Extra-spectrum warning

Type-II string achieves its UV completion with an infinite tower of massive string states. A hypothetical quartic-first KG seed that tries to retain only the massless spin-2 state must not borrow string-like coefficient rigidity while ignoring the UV states/Regge structure that make the string amplitude consistent.

This creates a useful causality/UV question:

> can the candidate derive comparable four-point rigidity without the additional spectrum, while maintaining unitarity, analyticity and causality?

If not, the seed is either incomplete or belongs to a broader string-like/extra-spectrum completion class.
