# P4 Hidden-Zero Cross-Order Nonuniqueness Gate

**Status:** permanent hard-seed origin prefilter.  
**KMQGB iteration:** 107.  
**Purpose:** prevent a hidden-zero locus from being mistaken for a unique gravitational parent when the same or closely related zero geometry survives across different higher-derivative orders.

## 1. Fresh comparator fact

Recent higher-derivative amplitude work extends hidden-zero phenomena beyond ordinary Einstein/Yang-Mills tree amplitudes. In particular, graviton amplitudes associated with the subleading low-energy bosonic closed-string corrections usually denoted `R^2` and `R^3` also exhibit hidden-zero / generalized-split structures.

Relevant references:

- Kang Zhou, *Hidden zeros for higher-derivative YM and GR amplitudes at tree-level*, arXiv:2510.11070.
- Liang Zhang and Kang Zhou, *Generalized 2-split for higher-derivative YM and GR amplitudes at tree-level*, arXiv:2601.00297.

Therefore

`hidden-zero pattern present`

is not by itself equivalent to

`Einstein order selected`

or to

`unique new hard parent selected`.

## 2. Structural nonuniqueness

Let a prospective zero law define a kinematic locus `Z=0` and suppose an allowed hard numerator/contact structure `N_0` vanishes on that locus.

Any further admissible structure of the schematic form

`N = N_0 + Z * P`

also vanishes on `Z=0` for arbitrary allowed `P` of compatible helicity/crossing/weight.

Likewise, if `N_0` contains `Z` as a factor, multiplication by additional crossing-compatible polynomials or higher-derivative invariants preserves the same zero.

As the derivative/order cutoff grows, the allowed space of such `P` generally grows unless an independent law fixes degree/growth/order.

This is the zero-locus analogue of the P4 functional-freedom no-go.

## 3. Required completion of a zero-based origin law

A zero-based P4 candidate must prospectively fix at least

1. **zero locus:** where the hard object vanishes;
2. **multiplicity/order:** how strongly it vanishes;
3. **degree or global growth class:** the allowed polynomial/transcendental complexity;
4. **pole/cut/singularity data:** so the zero law is not separated from analyticity/factorization;
5. **absolute normalization:** not fitted from the same target amplitude;
6. **helicity/multiplicity completion:** the rule must extend beyond a special MHV/truncated sector;
7. **same-parent Lorentzian/CTP mapping.**

Only the combined package can plausibly collapse the null space to finite dimension.

## 4. Cross-order test

For every candidate zero law `Z`, define a cutoff-dependent null space

`N_Z(D) = { Delta A : Delta A obeys declared symmetries/factorization class, vanishes on Z, and has derivative/growth order <= D }`.

Define

`ZF_D = dim N_Z(D)`.

If `ZF_D` grows without bound with `D`, the zero law alone is not a finite parent selector.

Classification:

`ZERO_LOCUS_ONLY__CROSS_ORDER_FUNCTIONAL_FREEDOM_BLOCKED`.

A finite value after adding a prospectively derived degree/growth law may continue to A3.
