# O4 Gisin–Stinespring Squeeze

**Status:** permanent O4 prefilter.  
**KMQGB iteration:** 082.  
**Purpose:** isolate the narrow consistency region in which a genuinely modified gravity-linked quantum dynamics could avoid both ordinary-environment degeneracy and the standard superluminal-signalling problem of deterministic nonlinear quantum mechanics.

## 1. Linear CPTP side

If the reduced observable state evolves by a linear completely-positive trace-preserving map, the Iter080 Stinespring gate applies:

`rho -> E(rho) = Tr_env[U(rho⊗rho_env)U†]`.

The reduced channel alone can therefore be reproduced by ordinary unitary dynamics on a larger Hilbert space. Fundamental modified quantum mechanics is not identified without additional joint gravity+matter observables or an obstruction to all admissible dilations.

## 2. Deterministic nonlinear side

Gisin (1990) showed that Weinberg-type nonlinear quantum mechanics permits arbitrarily fast communication in an EPR setting. Polchinski (1991) sharpened the issue: in Weinberg's nonlinear framework one encounters either EPR communication or communication between branches of the wavefunction unless separated-system structure is altered in a nonstandard way.

Therefore a deterministic state-dependent nonlinear Schrödinger law cannot be treated as a harmless way to escape Stinespring.

Classification:

`DETERMINISTIC_NONLINEAR_STATE_EVOLUTION__NO_SIGNALLING_AUDIT_MANDATORY`.

This is a guardrail, not the assertion that every logically possible nonlinear quantum theory has been ruled out.

## 3. The squeeze

The two controls create a narrow design region:

- **linear CPTP reduced dynamics** -> ordinary environment/dilation degeneracy;
- **generic deterministic nonlinear pure-state dynamics** -> EPR/branch-signalling risk;
- **stochastic nonlinear unraveling with linear CPTP ensemble evolution** -> returns to the dilation degeneracy at the reduced-channel level;
- **non-CPTP or nonlinear density-matrix dynamics** -> must independently establish probability consistency, positivity, composition and no-signalling.

Hence a genuine O4 parent cannot earn P4 credit merely by choosing one of these forms.

## 4. What can still survive

An O4 survivor must carry novelty in a **joint gravity+matter law**, for example a constraint tying geometry statistics, quantum state evolution and hard spin-2 response so that

1. the reduced matter channel alone is not the claimed certificate;
2. the full joint observable cannot be reproduced by an admissible unitary environment/classical stochastic-gravity comparator;
3. no-signalling follows from the parent rather than from post-hoc restrictions;
4. hard gravitational/CTP tensor structure is derived with the same finite data.

## 5. Search consequence

The safest next P4 synthesis route is therefore not an isolated modified Born/Schrödinger equation. It is a parent rule acting on the **joint gravitational process** and generating linked higher-point observables.

This agrees with the independent O3/Källén-Lehmann conclusion that novelty must move from isolated G2/reduced-channel data to higher connected and cross-representation structure.
