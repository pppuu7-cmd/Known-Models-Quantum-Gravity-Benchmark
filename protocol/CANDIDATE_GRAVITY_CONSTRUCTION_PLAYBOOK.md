# PHASE A — PRE-PARENT KILL TESTS

These stages occur **before** Promotion Gate G0.

## A1 — Parent capsule

Write a one-page parent capsule containing exactly:

- physical principle;
- explicit microscopic/equally constructive object or rule;
- declared physical domain;
- finite parent parameters/data;
- GR/infrared anchor;
- claimed beyond-C5 escape door(s) `E1..E5`;
- declared `S-local` or `D-nonlocal` analytic/spectral branch;
- first hard quantity claimed to be derived rather than fitted;
- same-parent CTP/retarded construction route.

### Stop condition A1

If no explicit parent object/rule exists, classify

`BLOCKED_NO_PARENT_OBJECT`

and do not proceed.

A slogan, symmetry name, duality name, gluing rule or arbitrary kernel is not an explicit parent.

## A2 — Functional-freedom gate

Authority: `protocol/P4_FUNCTIONAL_FREEDOM_NO_GO.md`.

For parent proposal `P`, define the structural-null hard-deformation space

`N_P = {delta A4 != 0 | all stated P constraints remain satisfied}`.

At increasing hard/EFT cutoff `D`, estimate

`FF_D(P)=dim N_P(D)`.

Use analytic counting when possible; otherwise use an exact symbolic/rank construction on the physical basis.

### Stop condition A2

If `FF_D` keeps growing with `D`, classify

`FUNCTIONAL_FREEDOM_BLOCKED`.

Examples of disallowed hidden freedom unless microscopically fixed:

- arbitrary crossing-symmetric `F(s,t,u)`;
- arbitrary positive spectral density `rho(mu)`;
- arbitrary nonlocal form factor;
- one independent Wilson coefficient at every order;
- arbitrary boundary function left by a functional equation.

The distinction is

`infinitely many predictions != infinitely many independent choices`.

A microscopic theory may predict an infinite EFT tower and still be low-freedom if the parent fixes the tower.

## A3 — Immediate novelty containment prefilter

Before detailed derivation, compare the parent object itself against the strongest known architecture classes:

- full C5 / ordinary quantum-gravity EFT;
- C4/C6 ordinary quantum mediator/source sectors;
- string / dual resonance / M-theory / matrix models;
- amplitude/bootstrap/double-copy/self-dual/integrable parents;
- asymptotic safety / spectral RG;
- LQG/spinfoam/GFT/tensor/discrete programs;
- HST/causal-diamond overlap constructions;
- spectral/noncommutative/nonassociative geometry;
- modern nonlocal/state-dependent alternatives.

### Stop condition A3

If the complete parent is already an instance/reparametrization/limit of a registered comparator architecture, preserve it as comparator evidence and classify

`COMPARATOR_CONTAINED_PRE_P4`.

Do not rename a known architecture as KG.

## A4 — P4 construction checkpoint

Only after A1–A3 survive, demand the actual P4 deliverable:

`parent object -> explicit derived hard 4pt/higher or cross-representation relation`.

It must include normalization, tensor/helicity/kinematic scope, parameter incidence, and the derivation path from the parent.

### P4 authorization

P4 can score only if all are present:

- explicit physical parent principle/object;
- low/finite hard freedom after A2;
- declared escape and analytic/spectral class;
- one nontrivial derived relation;
- plausible same-parent radiative/CTP/kinematic map;
- no immediate A3 containment.

Until then, no pre-ansatz promotion and no R4 increase.

# PHASE B — PROMOTION GATES G0–G10

Authority: `protocol/CANDIDATE_GRAVITY_PROMOTION_GATE.md` and `code/kg_candidate_record_validator.py`.

## G0 — One explicit parent dynamics

Freeze one action, Hamiltonian, master equation, CTP/influence functional, microscopic transfer rule or equivalent parent object.

All claimed source/noise/response/contact/higher-order quantities must descend from it or be explicitly external detector/source components.

**Artifact:** immutable parent authority reference + parameter table + declared domain.

**Fail closed:** missing provenance/object/domain -> `BLOCKED`.

## G1 — Same-parent response completeness

Authority: `protocol/PARENT_KERNEL_RESPONSE_COMPLETENESS.md`.

For inverse kernel `G=K^-1`, generate every ordered-partition family required at each response order.

Do not compare a selected diagram subset to a complete comparator response.

**Artifact:** response-family ledger with completeness status and zero/origin proofs for omissions.

**Stop:** any required family unsupported -> `BLOCKED`, never zero-filled.

## G2 — Exact physical reduction

Close before observable fitting:

- Ward/gauge identities;
- contact/seagull completion;
- conservation/Bianchi constraints;
- nonlinear Hamiltonian/momentum constraints where applicable;
- physical DOF reduction;
- exact routing/signature/normalization/phase conventions;
- repeated/coincident pole handling;
- source/native kinematic identity.

**Artifact:** physical-reduction certificate with executable regression where feasible.

**Stop:** convention or projection ambiguity that changes the observable -> `BLOCKED`.

## G3 — Common-domain comparator freeze

Freeze the identical

- observable definition;
- source/detector routing;
- perturbative/response order;
- state sector;
- background/kinematic domain;
- cut/amputation/contact convention

for candidate and comparator union.

**Artifact:** comparator-domain matrix.

**Stop:** UV-vs-IR, different-order or incomplete-domain comparison -> forbidden.

## G4 — Attribution stack

Require every applicable layer:

1. quantum attribution;
2. mediator attribution;
3. gravity / massless-spin-2 attribution;
4. locality/microcausality or declared controlled-nonlocal replacement;
5. relational/QRF attribution;
6. geometry attribution;
7. detector/backaction attribution;
8. regulator/continuum attribution;
9. state attribution.

**Artifact:** attribution ledger with explicit nulls/countermodels/evidence refs.

**Stop:** an ordinary quantum mediator, detector artifact, state effect or QRF redundancy can absorb the signal -> not KG-specific.

## G5 — Full comparator/full-C5 matching

Profile full applicable C0–C6/C3b plus benchmark-discovered stronger comparators on the frozen common domain.

Perform complete same-order full-C5 matching before calling anything `DeltaGamma_KG`.

**Artifact:** matched comparator package and residual vector `r`.

**Stop:** candidate feature is reproduced by a registered comparator -> preserve as negative evidence.

## G6 — Comparator-Orthogonal Residual

Authority: `protocol/RESIDUAL_SPACE_GEOMETRY.md`.

With covariance `Sigma` and union comparator Jacobian `J_union`, compute

`A = Sigma^(-1/2) J_union`,

`Pi_perp = I - A A^+`,

`COR = Pi_perp Sigma^(-1/2) r`.

**Artifact:** covariance, Jacobian, rank tolerances, singular spectrum and COR.

**Stop:** `COR=0` -> locally comparator-absorbed. Nonzero COR is only a local prefilter.

## G7 — Global/nonlinear separation

Profile finite comparator parameter/state/detector space on the prospectively frozen domain.

Require a pre-registered positive distance/robustness margin from the full comparator manifold.

**Artifact:** global profiling result + boundary/adversarial checks.

**Stop:** a finite comparator point absorbs the candidate -> no promotion.

## G8 — Observable design and projected identifiability

Authority: `protocol/OPTIMAL_COMPARATOR_CONTRASTS.md`.

For candidate Jacobian `J_KG`, evaluate

`B_KG = Pi_perp Sigma^(-1/2) J_KG`.

Require robust nonzero projected singular directions.

Prefer new observables that increase

`Delta d_perp = k - Delta rank(J_union)`

or materially improve the weakest projected singular value/SNR.

**Artifact:** projected singular spectrum and selected comparator-null contrasts.

**Stop:** adding precision to a rank-saturated observable set is not new residual dimension.

## G9 — Rigidity / shared-parameter prediction

Authorities:

- `protocol/CROSS_ORDER_RIGIDITY.md`;
- `protocol/CROSS_REPRESENTATION_RIGIDITY.md`;
- `protocol/CROSS_BACKGROUND_RIGIDITY.md`.

Shared parent parameters remain shared across orders, representations, configurations and valid backgrounds.

For stacked blocks, use shared-parameter rank deficit such as

`R_shared = sum_l rank(J_l) - rank(J_stack)`.

Where exact monomial scaling exists, derive nuisance-free invariants from the null space of the exponent matrix rather than fitting independent coefficients.

**Artifact:** parameter-incidence graph + cross-order/representation/background predictions.

**Stop:** each new effect requires a new independent coefficient -> return to A2; likely functional-freedom failure.

## G10 — Promotion and downstream statistics

Only after G0–G9 are `PASS` may an ansatz be promoted for Candidate Gravity model-readiness accounting.

Only after a robust global comparator-subtracted residual exists may Fisher/resources/experimental optimization be scientifically promoted.

**Artifact:** validated v1.1+ candidate record + immutable promotion decision.

**Stop:** any non-PASS mandatory gate forbids ansatz promotion.

# PHASE C — PREDICTIVE HOLDOUT

A promoted or near-promoted parent must predict at least one pre-registered block not used to tune its shared parameters.

Authority: `protocol/PREDICTIVE_HOLDOUT.md` where applicable and the repository holdout reference implementation.

Rules:

- freeze training parameters before opening holdout values;
- do not retune shared parameters on holdout;
- use the same parent conventions and comparator domain;
- preserve a failed holdout as scientific evidence rather than redefining the parent after inspection.

A holdout is stronger when it changes order, representation, background or attribution channel while retaining the same parent parameters.

# PHASE D — COMPUTE TRIAGE

## Heavy compute is forbidden when the blocker is structural

Do **not** launch large numerical jobs merely because compute is available if the unresolved question is any of:

- missing parent object;
- growing functional freedom;
- missing normalization/sign convention;
- unsupported response family;
- missing exact kinematic map;
- missing comparator definition;
- missing attribution proof.

These are algebraic/authority blockers.

## Heavy compute becomes justified only when it can discriminate a frozen object

Examples:

- calculate a previously derived hard kernel on a registered grid;
- perform global comparator-manifold profiling after all common-domain definitions are frozen;
- evaluate projected singular spectra/covariance over a fixed design;
- run nonlinear holdout predictions without parameter retuning;
- test continuum/large-N/regulator convergence for a fixed microscopic parent.

Before launch record:

- exact scientific question;
- frozen input commit/artifact hashes;
- success/fail/block thresholds;
- expected output artifact;
- authority rule for duplicate/racing runs.

# PHASE F — ONE-PAGE DECISION TREE

Use this exact order:

`raw idea`

`-> explicit parent?`  
No -> `BLOCKED_NO_PARENT_OBJECT`.

`-> finite hard freedom under FF_D?`  
No -> `FUNCTIONAL_FREEDOM_BLOCKED`.

`-> already comparator-contained at architecture level?`  
Yes -> preserve as comparator evidence.

`-> explicit derived hard/cross-representation relation?`  
No -> P4 remains open.

`-> complete same-parent response + exact physical reduction?`  
No -> `BLOCKED`, no zero-fill.

`-> common-domain attribution/comparator freeze?`  
No -> `BLOCKED`.

`-> nonzero local COR?`  
No -> locally absorbed.

`-> survives global comparator manifold?`  
No -> globally absorbed.

`-> identifiable + rigid + predictive holdout?`  
No -> not promotable.

`-> all G0-G9 PASS?`  
Yes -> ansatz promotion allowed; only then downstream Fisher/resources.
