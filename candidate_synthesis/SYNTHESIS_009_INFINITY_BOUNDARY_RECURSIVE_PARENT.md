## 1. Parent capsule

`A_n = A_n^(finite poles) + B_n`,

where `B_n` is the boundary-at-infinity contribution.

> the quantum-gravity hard hierarchy is the unique crossing-compatible solution whose boundary data recursively factorize into lower-point gravitational boundary/amplitude data.

Schematic finite rule:

`B_n = K_n[A_(n-1), kinematics]`,

This is more promising than an arbitrary contact ansatz because the first hard datum is placed exactly where ordinary finite-pole factorization ceases to determine the amplitude.

`A1 PARTIAL_PASS__HARD_BOUNDARY_LOCATION_AND_RECURSIVE_ARCHITECTURE_EXPLICIT`.

## 3. A2 — two branches

### 3.1 Use the observed Einstein-gravity infinity law

If `K_n` is chosen to be the known factorization-like boundary behavior of ordinary Einstein amplitudes, the recursion is finite and rigid, but it reconstructs a comparator.

`A2 PASS_AS_COMPRESSION_CONTROL`.

No arbitrary tower is introduced, but no new theory is selected.

### 3.2 Deform the infinity law

Write schematically

`K_n = K_n^GR + Delta K_n`.

Unless a separate finite physical law determines the full sequence/function `Delta K_n`, the functional-freedom problem has simply moved from `A_n` to the boundary law.

If each multiplicity gets an independent correction, freedom grows with `n`.

If `Delta K_n` is generated by a finite recursion, it may pass A2 but must then face A3; the recursion itself is the true proposed parent datum.

Therefore the infinity framework alone does not close functional freedom.

## 4. A3 — decisive comparator fork

The candidate has a fail-closed trichotomy.

1. **Known GR boundary law** -> `A3 FAIL__EINSTEIN_GRAVITY_BOUNDARY_RECURSION_CONTAINED`.
